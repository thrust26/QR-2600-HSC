# QR Code Generator for Atari 2600 and PlusROM High Score Club
Copyright 2021/2026 - Thomas Jentzsch

## The Code
The code is supposed to generate QR codes for sending high scores to the [PlusROM HSC](https://highscore.firmaplus.de) using carts and stock consoles. Although it's designed specifically for the Atari 2600, it should be fairly easy to adapt to other consoles.
